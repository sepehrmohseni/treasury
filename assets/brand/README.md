# The Treasury mark

A treasury facade whose columns are table cells, with a header row and a keyhole in the pediment:
where your data is kept, and the credentials that open it. Flat shapes on a 1024 grid, ledger green
`#1E5640` and paper white `#F4F0E6`, no gradients or shadows.

| File | Use |
|---|---|
| `icon.svg` | App icon for Windows, Linux and stores, 48 px and up |
| `icon-small.svg` | The same icon for 16 to 32 px: solid columns, no keyhole |
| `icon-macos.svg` | macOS: the 824 px body of Apple's icon grid |
| `icon-ios.svg` | iOS: opaque square, the system applies the mask |
| `adaptive-foreground.svg` | Android adaptive icon foreground; the background layer is solid `#1E5640` |
| `adaptive-monochrome.svg` | Android 13 themed icon layer |
| `notification.svg` | Notification and tray icon: white silhouette on transparent |

These SVGs are the sources. The PNG, ICO and ICNS files the bundles need are generated from them;
do not edit the generated files by hand.
