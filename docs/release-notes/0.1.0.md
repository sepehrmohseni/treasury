Treasury 0.1.0 is the first release: an open-source database client for PostgreSQL, MySQL,
MariaDB, SQL Server and MongoDB, on Linux, macOS and Windows. It has no account, no paid tier and
no telemetry.

## What it does

- Add connections by hand, from a connection string, or by importing the connection files that
  other database clients export. Passwords go to the system keychain, never to a settings file.
- Browse databases, schemas, tables and collections in a tree that loads as you open it.
  Double-click a table to see its rows.
- Write statements in an editor that highlights them, and run the one under the cursor with
  Ctrl+Enter. Plain SELECTs get a 1,000-row limit unless you turn it off.
- Read results in a grid that fetches only the rows in view.
- Edit the rows of a result that comes from one table with a primary key or a unique key.
  Changes collect in the grid; you read the UPDATE and DELETE statements they become before they
  run, together, in one transaction.
- Export a result to CSV, JSON, NDJSON or Parquet. Export streams straight to the file.
- Connect through SSH tunnels, and decide about each new SSH host key yourself.
- Choose the theme, the default row limit, history, tips and the version check in Settings. A
  short walkthrough on first launch can be skipped and brought back from there.

## Guardrails

Treasury reads every statement before the server does.

- Production connections open read-only. Unlocking writes lasts 15 minutes.
- On any connection that is not local, an UPDATE or DELETE first shows how many rows it would
  change. One without a WHERE clause, one that changes more than 1,000 rows, or one Treasury
  cannot count asks you to type the connection name.
- On production, DROP, TRUNCATE and ALTER ask for the connection name too.
- Production connections keep no query history unless you turn it on.

## Downloads

| Platform | Files |
|---|---|
| Linux x64 | `.AppImage`, `.deb`, `.rpm` |
| Linux arm64 | `.AppImage`, `.deb`, `.rpm` |
| macOS, Apple silicon and Intel | `.dmg` |
| Windows x64 | `-setup.exe` installer, `.msi` |

Before the first launch:

- macOS: the app is not notarized by Apple yet, so macOS stops it the first time. Open it once,
  then choose Open Anyway in System Settings, Privacy & Security.
- Windows: the installers are not code-signed yet, so SmartScreen may warn you. Choose More info,
  then Run anyway.
- Linux: install the `.deb` or `.rpm` with your package manager, or make the AppImage executable
  and run it. Passwords go to the Secret Service (GNOME Keyring or KWallet).

## Checking a download

`SHA256SUMS` lists the checksum of every file; check yours with
`sha256sum -c SHA256SUMS --ignore-missing`. Every file also has a build provenance attestation,
which `gh attestation verify <file> --repo sepehrmohseni/treasury` checks, and the CycloneDX SBOM
lists every dependency.

## Updates

Treasury asks GitHub once at start whether a newer version exists; Settings turns that off. It
installs an update only when you choose Install and restart, and only if the update is signed
with the project's key.
