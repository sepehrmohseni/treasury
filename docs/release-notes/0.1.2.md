Treasury 0.1.2 fixes a window that did not fit smaller screens, shows why a connection could not
be opened where you are looking, and lets you change when a Redis key expires.

## Fixed

- The window opened at 1280 by 800 whatever the screen. On a laptop screen, or with display
  scaling, its bottom edge sat behind the taskbar, and the status bar and the buttons of long
  dialogs went with it. The window now fits the screen it opens on: centered when it fits,
  otherwise sized to the screen and maximized.
- Dialogs keep their title and buttons in view and scroll what is between them. An error in a
  dialog appears just above its buttons.
- A connection that could not be opened only said why in the status bar. Now the message from
  the server, or from the SSH host, appears under the toolbar with Try again and Edit
  connection, and under the connection's name in the list.

## Changed

- Each connection in the list is marked as connected, connecting or failed, and the one you are
  working in stands out.
- Run and Run all say "Connect first" while there is no open connection to run on.
- With connections saved, the first screen says to click one, and where its databases and tables
  appear.

## Added

- Redis and Valkey: the bar under a key's rows shows when the key expires. Set a new expiry, or
  none, and it is saved with the other changes, in the same MULTI/EXEC, after you have read the
  EXPIRE or PERSIST it becomes. An expiry of 0 seconds, which would delete the key, is refused.

## Updating from 0.1.1

Treasury 0.1.1 offers the update in its status bar, at the bottom of the window, the next time
it starts. If that edge is hidden behind the taskbar, maximize the window first (double-click its
title bar). Choose Install and restart.

## Downloads

| Platform | Files |
|---|---|
| Linux x64 | `.AppImage`, `.deb`, `.rpm` |
| Linux arm64 | `.AppImage`, `.deb`, `.rpm` |
| macOS, Apple silicon and Intel | `.dmg` |
| Windows x64 | `-setup.exe` installer, `.msi` |

Before the first launch:

- macOS: the app is not notarized by Apple yet, so macOS stops it the first time. Open it once,
  then choose Open Anyway in System Settings, Privacy & Security.
- Windows: the installers are not code-signed yet, so SmartScreen may warn you. Choose More info,
  then Run anyway.
- Linux: install the `.deb` or `.rpm` with your package manager, or make the AppImage executable
  and run it. Passwords go to the Secret Service (GNOME Keyring or KWallet).

## Checking a download

`SHA256SUMS` lists the checksum of every file; check yours with
`sha256sum -c SHA256SUMS --ignore-missing`. Every file also has a build provenance attestation,
which `gh attestation verify <file> --repo sepehrmohseni/treasury` checks, and the CycloneDX SBOM
lists every dependency.
