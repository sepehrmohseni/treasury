Treasury 0.1.3 brings a database navigator and an editor for each table, so a database can be
browsed and read without writing a query, and lets you check for a new version whenever you like.

## Added

- The navigator. Every connection is a node of one tree on the left. Expand a connection to
  open it and see its databases, schemas, tables, views, materialized views, functions,
  sequences and types; expand a table for its columns and indexes. Several connections can be
  open at once. The toolbar above the tree adds and imports connections, reads the selected
  connection's objects again, and collapses the tree; the box under it filters connections by
  name.
- Right-click menus. On a connection: Connect or Disconnect, Open SQL editor, Refresh and Edit
  connection. On a table or other object: Open, View data, Read in a SQL editor, Copy name and
  Refresh.
- Table editors. Double-click a table, view or collection to open it in a tab of its own.
  Properties lists its columns (type, not null, default, primary and foreign keys, comment), its
  indexes, its foreign keys, its DDL, which you can copy or open in a SQL editor, and facts such
  as its size. Data shows its rows in the grid, where you can edit, add and delete rows as
  before; Refresh reads them again. Functions, sequences, types, indexes, triggers and other
  objects open at their DDL.
- Check now, in Settings, asks GitHub for a newer version at once and offers Install and
  restart when there is one. An open Treasury also asks again every 6 hours unless the check is
  turned off.
- The sidebar can be dragged wider or narrower, and keeps its width. Double-click its edge to
  reset it.

## Changed

- Clicking a connection opens it and expands it in the navigator. Editing a connection moved
  from a double-click to its right-click menu.

## Downloads

| Platform | Files |
|---|---|
| Linux x64 | `.AppImage`, `.deb`, `.rpm` |
| Linux arm64 | `.AppImage`, `.deb`, `.rpm` |
| macOS, Apple silicon and Intel | `.dmg` |
| Windows x64 | `-setup.exe` installer, `.msi` |

Updating from 0.1.2: Treasury offers the update in the bar at the bottom of its window when it
starts. Choose Install and restart. Or run the new installer over the old version; there is no
need to uninstall, and your connections and passwords stay.

Before the first launch:

- macOS: the app is not notarized by Apple yet, so macOS stops it the first time. Open it once,
  then choose Open Anyway in System Settings, Privacy & Security.
- Windows: the installers are not code-signed yet, so SmartScreen may warn you. Choose More info,
  then Run anyway.
- Linux: install the `.deb` or `.rpm` with your package manager, or make the AppImage executable
  and run it. Passwords go to the Secret Service (GNOME Keyring or KWallet).

## Checking a download

`SHA256SUMS` lists the checksum of every file; check yours with
`sha256sum -c SHA256SUMS --ignore-missing`. Every file also has a build provenance attestation,
which `gh attestation verify <file> --repo sepehrmohseni/treasury` checks, and the CycloneDX SBOM
lists every dependency.
