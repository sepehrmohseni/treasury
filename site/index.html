Treasury
How it decides Engines Source

A database client that reads your SQL before the server does.

Treasury is an open-source desktop and mobile client for PostgreSQL, MySQL, SQL Server, MongoDB, Redis, Cassandra, Snowflake, Databricks, Oracle and Db2. It knows which statements write, counts the rows an UPDATE or DELETE would change, and keeps production read-only until you unlock it.

What happens when you press Run on production

Production connections open read-only, and anything that could write is refused. Unlocking writes lasts 15 minutes. These ten statements show what Treasury does with each, before and after the unlock.

What leaves your machine

Very little, and nothing without a reason you can see.

Your databases and SSH hosts
Contacted when you connect. TLS is on by default and certificates are verified.
Passwords and keys
Kept in the system keychain: macOS Keychain, Windows Credential Manager, the Secret Service on Linux. Never in the settings file.
Query history
Stored on your machine and encrypted. It is searchable only while the app is open.
Everything else
No account, no analytics, no crash reports. The app's only automatic request will be an update check to GitHub, which you can turn off. This page loads nothing from other sites.
