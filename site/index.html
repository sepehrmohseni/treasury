Treasury

An open-source desktop and mobile client for PostgreSQL, MySQL and MariaDB, SQL Server, MongoDB, Redis and Valkey, Cassandra and ScyllaDB, Snowflake, Databricks SQL, Oracle and Db2.

Status In development. There is no release yet; the first one will be 0.1.0. Progress is public in the commit history.

What it is built to be

Free and complete
No account, no paid tier, no engine held back. Licensed MIT or Apache-2.0.
Careful with production
Production connections open read-only. Updates and deletes outside your own machine show how many rows they would change before they run. On production, dropping, truncating or altering a table asks you to type the connection name.
Built for large results
Rows are read from the server as you scroll, so a result of millions of rows does not have to fit in memory.
Usable without a model
Model features are optional and use your own key with the provider you choose. Nothing depends on them.

What goes over the network

Your databases and SSH hosts
When you connect to them.
A model provider
Only if you set one up, only when you run a model action, and only after Treasury shows you exactly what it will send. Schema metadata by default; row values only when you tick a box for that request.
GitHub
An update check, which you can turn off on the first screen. It is the only request Treasury makes on its own.
Nothing else
No analytics, no crash reports, no remote fonts, scripts or images. This page loads nothing from other sites either.
